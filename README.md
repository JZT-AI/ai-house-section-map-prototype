# ai_house 板块全景原型

在线原型入口：[index.html](./index.html)。

仓库包含：

- `index.html`：交互原型，含真实电子围栏快照。
- `PRD.md`：产品需求与验收规则。
- `master_data_service_hd_ai_house_section.xlsx`：原型引用的围栏源表。

## 使用高德真实地图

打开页面后，点击“配置高德真实底图”，填写高德 Web端（JS API）Key；开发原型可填写安全密钥。生产环境应通过安全代理配置安全密钥，不要将密钥提交到仓库。

GitHub Pages 域名白名单请配置：`jzt-ai.github.io`。
